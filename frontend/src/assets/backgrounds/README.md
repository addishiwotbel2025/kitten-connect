# Background cat photos

Drop your cat images in **this folder** and they'll automatically be picked up
and rotated as the page background — no code changes needed.

- Supported types: `.jpg`, `.jpeg`, `.png`, `.webp`
- Add as many as you like (3–6 looks good).
- They fade from one to the next automatically every few seconds.

Example filenames:
```
ginger-cat.jpg
sleepy-kitten.png
tabby.webp
```

If this folder has no images, the page falls back to a warm ginger gradient.
